# KeyPet на Windows

Проект разрабатывается на Windows: все команды — PowerShell-скрипты, запускаются из корня проекта.

> Windows по умолчанию не запускает `.ps1`. Либо один раз разрешите локальные скрипты для своей учётной записи:
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, либо запускайте каждый так:
> `powershell -ExecutionPolicy Bypass -File tools\sim.ps1 check`.

| Команда                                     | Что делает                                              |
|---------------------------------------------|---------------------------------------------------------|
| `tools\setup-windows.ps1`                   | ставит все инструменты (один раз)                       |
| `tools\sim.ps1 build`                       | pipsim + face/voice/maze/pet_test                       |
| `tools\sim.ps1 check`                       | smoke-набор, всё должно быть `ok`                       |
| `tools\sim.ps1 run out\x.png 1.5 "0.3:P"`   | один сценарий → PNG/GIF/MP4 + строка status             |
| `tools\sim.ps1 web`                         | веб-симулятор на http://localhost:8466                  |
| `firmware\flash.ps1 [сек] [-Port COM5]`     | сборка, прошивка, лог платы                             |
| `python firmware\serlog.py 20 --reset`      | только лог (порт находится сам, по VID 0x303A)          |
| `tools\pipdebug.ps1`                        | отладочная страница http://localhost:8765               |
| `tools\release.ps1`                         | `docs/firmware/firmware.js` + `version.js` для панели   |
| `tools\fonts.ps1`                           | шрифты тем из `assets/fonts`                            |
| `offline-panel.bat`                         | оффлайн-панель (файлом) в Chrome/Edge                   |
| `local-servers.bat`                         | панель :8465 и симулятор :8466, пока открыто окно       |

## Установка (один раз)

Нужны Git (`winget install Git.Git`) и Python 3 с python.org (не заглушка из Microsoft Store). Затем:

```
powershell -ExecutionPolicy Bypass -File tools\setup-windows.ps1
```

Скрипт ставит через winget CMake, Ninja, LLVM-MinGW (clang для pipsim), FFmpeg (pipsim пишет картинки через него);
через pip — Pillow и pyserial; скачивает LVGL 9.5.0 в `third_party\lvgl`, emsdk в `%USERPROFILE%\emsdk` и ESP-IDF
v5.5.6 в `%USERPROFILE%\esp\esp-idf`. Повторный запуск пропускает готовое.
Ключи: `-NoFirmware` (без ESP-IDF, ~3 ГБ), `-NoWeb` (без emsdk, ~1 ГБ).

Если в Windows включён системный SOCKS-прокси (VPN-клиенты v2rayN, Nekoray и т. п.), pip и загрузчик ESP-IDF его не
понимают — скрипт замечает это и качает напрямую (`NO_PROXY=*`).

Если загрузка большого архива зависает, его можно скачать браузером (с VPN) и положить в кэш с точным именем из лога:
архивы emsdk — в `%USERPROFILE%\emsdk\downloads\`, тулчейны ESP-IDF — в `%USERPROFILE%\.espressif\dist\`; при
повторном запуске установщики берут готовый файл и только распаковывают его.

Прошивке `third_party\lvgl` не нужна: ESP-IDF берёт LVGL из своего менеджера компонентов (`idf_component.yml`).

## Прошивка

Подключите брелок по USB-C и запустите `firmware\flash.ps1` (по умолчанию 13 с лога после прошивки). Порт ищется по
VID Espressif (0x303A), обычно это `COM3`…`COM9`; можно указать явно: `firmware\flash.ps1 20 -Port COM5`. Отладочную
страницу (`tools\pipdebug.ps1`) перед прошивкой остановите — она держит порт. Если плата не видна, зажмите BOOT и
нажмите RESET.

Прошить готовую публичную сборку можно и без всего этого: `offline-panel.bat` открывает панель `docs\index.html`.

## Как тестировать без платы

Весь интерфейс (`ui/`) компилируется без изменений и в прошивку, и в оба симулятора, поэтому почти всё, кроме железа
(дисплей, датчики, Bluetooth, энергопотребление), проверяется на компьютере.

### 1. Веб-симулятор — руками

```
tools\sim.ps1 web
```

Откроется http://localhost:8466: 3D-модель брелока и панель управления справа.

- **Экран** — мышь вместо пальца: клик = касание, с зажатой кнопкой мыши — вести пальцем (Пип следит глазами).
  Готовые жесты — кнопки «Тык», «Тык ×3», «Погладить».
- **Кнопки корпуса** — кликните по боковым кнопкам на модели или по «Верхняя · меню / открыть» и «Нижняя · назад».
  Верхняя открывает меню и приложения, нижняя — назад; нижняя на экране Пипа — «знакомство».
- **Наклон** — тяните точку на квадрате: это акселерометр, глаза «скатываются» вниз. «Встряхнуть» → головокружение,
  «Экраном вниз» → засыпает и гаснет экран, «Ходьба» → считает шаги.
- **Темы** — Стандартная, Ретро, Барби (на брелоке: Настройки → Темы).
- **iPhone (поддельный)** — сопряжение, уведомление, звонок, музыка; **компьютер** — для приложения «Пульт»
  (журнал HID-нажатий виден под кнопками). С зажатым Shift: клик по экрану и тянуть — указка гироскопом.
- **Тамагочи** — покормить, поиграть, ускорить время ×60/×600, +1/+8 часов: так видно голод, сон, ночное настроение.
  Питомец сохраняется в браузере между запусками.
- **Голос** и **Настроение** — послушать голоса и показать любую эмоцию по имени.

После правок в `ui/` пересоберите (`tools\sim.ps1 web-build`) и обновите страницу (кэш отключён).
Модель брелока подгружает three.js с cdn.jsdelivr.net — нужен интернет.

### 2. pipsim — автоматически и воспроизводимо

`pipsim` прогоняет сценарий с фиксированным временем и пишет последний кадр (`.png`) или ролик (`.gif`, `.mp4`),
а последней строкой печатает состояние: `status: mood=… reaction=… screen=… theme=… display=…`.

```
tools\sim.ps1 run out\look.png 1.5 "0.05:H0 0.3:k5 0.4:d20,233"   # палец слева: Пип смотрит туда
tools\sim.ps1 run out\menu.gif 3 "0.05:H0 0.3:P 1.5:onoise"        # меню, затем шумомер
tools\sim.ps1 run out\sleep.png 3 "0.2:a0,0,-1"                   # экраном вниз: display=0
tools\sim.ps1 run out\dizzy.gif 2 "0.3:S 1.3:S"                   # встряхнули: mood=dizzy
tools\sim.ps1 run out\call.gif 4 "0.2:L2 1:C1 3:C0"               # iPhone, звонок и сброс: reaction=missed
tools\sim.ps1 run out\diag.gif 3 "0.05:H1 0.3:P 1:P"              # тема Ретро: меню, затем Пип
```

События — `<секунда>:<код>` через пробел (полный список — в начале `sim\main.c`):
`d<x>,<y>`/`m`/`u` палец, `P`/`B` верхняя/нижняя кнопка, `o<app>` открыть приложение, `a<x>,<y>,<z>` акселерометр,
`S` тряска, `W` ходьба, `V<дБ>`/`Q` шум и дуновение в микрофон, `J<%>[+]` батарея, `n<эмоция>` закрепить эмоцию,
`T<часы>` сдвиг часов, `F`/`G` покормить/поиграть, `L`/`N`/`C`/`M` поддельный iPhone, `X` компьютер,
`H<n>` тема, `E1` энергосбережение, `K<ручка>=<v>` порог дерева настроений, `R` редкая карточка.

Списки эмоций и приложений: `.\build\pipsim.exe --list`.

### 3. Smoke-набор

```
tools\sim.ps1 check
```

~220 проверок: глаза следят за пальцем и наклоном, реакции срабатывают от настоящих входов (касание, IMU, кнопки,
микрофон), каждое приложение открывается, темы не путают элементы, юнит-тесты рендера лица, голоса, лабиринта и
дерева настроений. Всё должно быть `ok`. Добавляя реакцию или приложение — добавьте проверку в `sim\check.py`.

### Что симулятор не покажет

Реальную скорость (fps и время кадра меряйте на плате: лог `flash.ps1` каждые 5 с), оттенки тёмных цветов на AMOLED,
настоящий Bluetooth с iPhone, энергопотребление и сон чипа, свободную внутреннюю RAM.
